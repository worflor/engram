# Reference unification

This repository defines the maintained reference for Engram's mathematical behavior.
Consumers remain unchanged until separately migrated. Preserve Alexandria's frozen bytes.

## Source decisions

- Portfolio, Séance and Rhema share the same Python functional surface (AST comparison); retain the richer Python memory/generation model as the functional reference.
- Neuron supplies the native Rust kernels, bounded brain reader and streaming-continuity regression.
- WDYM contributes the explicit AR(1) short-observation path and memory interchange cases; game services remain host integration.
- Manifold contributes paired K/G signatures, spectral diagnostics and the ENDB representation of Alexandria; application-specific hunk graph policy stays in Manifold.
- Historical witness-family encoders are earlier, incompatible constructions. Wick's corpus-IDF sparse projection is a distinct text embedding with the same name, not the AR(2) trajectory codec; preserve that distinction rather than merging unrelated math.
